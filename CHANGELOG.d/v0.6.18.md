# v0.6.18

### Added

- Implemented Automation backlog item **A4 Timed Waveform Logging**.
- Added a Timed Waveform Logging mode that periodically saves one full enabled-channel CSV record and does not capture a screenshot.
- Reused the existing no-overlap/no-backlog periodic scheduler so a slow CSV transfer causes later timer ticks to be skipped rather than queued.
- Added framework-neutral `save_full_record_csv(...)` orchestration that reads the current record length and requests that full point count from the public waveform CSV API.
- Added structured non-transport output failure handling and tests for full-record point-count propagation.
- Added A4 mode/action presentation and Current Run CSV status integration.

### Version

- Package version bumped to `0.6.18`.

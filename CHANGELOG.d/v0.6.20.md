# v0.6.20

### Added

- Implemented Automation backlog item **A5 Measurement Logger**.
- Added a Measurement Logger mode with selectable MEAS1..MEAS8 slots and periodic sampling through the existing no-overlap scheduler.
- One append-only CSV is created per run with fixed columns: UTC timestamp, local timestamp, elapsed seconds, then the selected MEAS columns.
- Selected measurement slots are snapshotted when the run starts so columns cannot drift while logging.
- Non-transport per-slot read failures produce an empty field plus a diagnostic while transport failures still propagate to the session recovery path.
- Added framework-neutral CSV append logic and regression coverage for headers, elapsed time, slot validation, unavailable values, and transport failures.

### Version

- Package version bumped to `0.6.20`.

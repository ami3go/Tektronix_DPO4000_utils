# v0.6.40

### Added

- Implemented Logger backlog item **L4 Binary waveform output**.
- Added the dependency-free append-only `DPO4LOG` container with schema version, run header, length-prefixed record frames, CRC32 validation and compact raw waveform sample payloads.
- Added a scanner/reader that preserves all complete frames and reports a truncated/corrupt final frame without discarding prior records.
- Logger output can now be CSV, Binary DPO4LOG, or both.

### Version

- Package version bumped to `0.6.40`.

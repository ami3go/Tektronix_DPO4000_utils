# v0.6.35

### Added

- Implemented Automation backlog item **A12 Automation Report**.
- Every reportable Automation scope operation is durably appended to JSONL and CSV event logs with UTC timing, cause, status, retry count, artifact paths and error details.
- Added an atomic final JSON run summary containing configuration/profile snapshot, resource/IDN, counters, retry/reconnect statistics, retention statistics, stop reason and final error.
- Event files are flushed/fsynced as they are appended, so completed records remain readable if the process/PC stops before final summary creation.
- Report finalization is idempotent and is invoked for Run once completion, natural completion, limits/safety stops, user Stop and application close.

### Version

- Package version bumped to `0.6.35`.

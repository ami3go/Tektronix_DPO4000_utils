# v0.6.2 - 2026-08-28

## Added

- Added a full real-hardware public API verifier with `read-only`, `reversible`, and `full` safety profiles.
- Added reflection-based coverage enforcement for every public `DPO4000Scope` method and exported package function, so CI detects verifier drift when the API grows.
- Added Markdown, HTML, and JSON verification reports plus scope-setup, screenshot, and waveform evidence artifacts.
- Added automatic initial-setup capture and final setup restoration for write-capable bench qualification runs, including restoration after a failed write case.
- Added a separately guarded `save_waveform_to_reference()` qualification path requiring explicit REF-overwrite authorization.
- Added `docs/hardware-verification.md` and a bench runner at `scripts/run_hardware_verification.py`.

## Changed

- The self-hosted Hardware API Tests workflow can run the full verifier, retains evidence artifacts for 90 days, and still executes the focused pytest hardware suite.
- Package version bumped to `0.6.2`.

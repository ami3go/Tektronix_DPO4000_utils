# v0.6.64 — Qt public-driver boundary cleanup

- Removed raw PyVISA resource access from the active legacy Qt inheritance layers.
- Replaced GUI-owned IDN, hardcopy, waveform export, settings restore, acquisition, display, and measurement SCPI paths with public `DPO4000Scope` APIs.
- Moved short-lived GUI session setup to the driver-owned `scope_session()` lifecycle so timeout and termination handling no longer touches the underlying VISA object.
- Removed duplicated acquisition, measurement, and display SCPI query maps from GUI modules.
- Added a regression test that rejects `scope.scope`, raw `query`/`write`, and GUI-owned SCPI query maps in the four legacy active layers.

# v0.6.36

### Fixed after A12 review

- Synchronous Run once reporting now defers final JSON summary creation until the outer mode handler has updated success/failure counters and artifact state.
- Asynchronous trigger-style Run once operations continue to finalize through the report watchdog after the controller returns idle.
- This removes a reconciliation race where a valid Run once event could appear in the event log but the summary still showed zero successes.

### Version

- Package version bumped to `0.6.36`.

# v0.6.42

### Added

- Implemented Logger backlog item **L5 Measurement Logger**.
- Added Measurements mode with selectable MEAS1..MEAS8 slots and fixed-column append-only CSV output.
- Measurement rows include UTC/local timestamps, elapsed time, record sequence, fixed MEAS columns and structured unavailable-value status.
- DPO4LOG records preserve the same measurement snapshot/error data when Binary output is selected.
- Non-transport invalid/overflow measurement values are recorded as unavailable; transport failures still propagate to recovery handling.

### Version

- Package version bumped to `0.6.42`.

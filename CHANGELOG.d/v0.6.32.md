# v0.6.32

### Fixed after A10 review

- Automation profile numeric values must now be finite; `NaN`/infinite JSON values are rejected on save and load.
- Profile application now performs a complete UI compatibility/range preflight before the first widget is changed, preventing partial configuration application on malformed/incompatible documents.
- Preflight validates mode availability, widget names/types/ranges, combo choices, File fields and measurement-slot booleans.

### Version

- Package version bumped to `0.6.32`.

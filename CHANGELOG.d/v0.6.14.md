# v0.6.14

### Added

- Implemented Automation backlog item **A2 Image on Trigger**.
- Added public driver acquisition-state and trigger-state readback APIs based on the Tektronix DPO4000 programmer-manual commands.
- Added `Image on Trigger` mode to the Automation tab with a default 500 ms status-poll interval and optional automatic Single re-arm after each saved image.
- A2 arms a Single acquisition, waits on the existing worker thread until the acquisition system is stopped and the trigger system reports the documented saved state, then saves exactly one PNG before optional re-arm.
- Trigger waiting is cancellable from Pause/Stop without running instrument polling on the GUI thread.
- Trigger Automation uses only public driver methods: `single_acquisition()`, `get_acquisition_state()`, `get_trigger_state()`, `stop_acquisition()`, and `save_image_path()`.
- Added Qt-independent trigger-cycle state/counter models plus acquisition/trigger-state driver tests.
- Added a driver-boundary regression test for the A2 GUI layer.

### Version

- Package version bumped to `0.6.14`.

# v0.6.46

### Added

- Implemented Logger backlog item **L8 File Rotation**.
- Logger output sessions now rotate only between complete records.
- Added OR-combined thresholds for projected segment size, segment duration, record count, and UTC date boundary.
- Segment names use a stable run timestamp plus a zero-padded segment index.
- Added live segment index, rotation count, and last-rotation reason to the Logger health panel.
- Default unattended policy is 1 GB or 1 hour, whichever is reached first.

### Version

- Package version bumped to `0.6.46`.

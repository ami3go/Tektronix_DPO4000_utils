# v0.6.68 — Harden permanent Qt GUI boundary regression

- Refined the recursive Qt GUI AST boundary scanner so common file APIs such as `Path.read_bytes()` and debug-log `.write()` are not mistaken for instrument transport calls.
- Added exact, context-qualified fingerprints for the remaining pre-existing GUI transport/SCPI debt. The test now fails if any new debt appears, if a legacy count grows, or if cleaned debt is not removed from the baseline in the same change.
- Expanded the guarded GUI-owned SCPI map set to include the legacy channel and MATH query maps, keeping future GUI modules behind public `dpo4000_utils` driver APIs.

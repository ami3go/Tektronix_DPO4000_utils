# v0.6.54

### Added

- Implemented Logger backlog item **L13 Runtime Health**.
- Added framework-neutral health accounting for successful scope-side records without retaining waveform payloads.
- Logger now shows elapsed run time, captured/effective records per second, waveform points per second, raw waveform payload throughput, disk throughput, writer duty cycle, queue pressure/peak memory, current segment/total bytes, MEAS rows, BUS event totals, last-record integrity, resource/session/recovery state, last error, and disk runway.
- Runtime health distinguishes Logger-observed waveform transfer rates from the oscilloscope acquisition sample rate.
- Health elapsed time freezes after Stop/terminal failure instead of decaying rates forever while idle.
- Added focused health-metric and GUI driver-boundary regression coverage.

### Version

- Package version bumped to `0.6.54`.

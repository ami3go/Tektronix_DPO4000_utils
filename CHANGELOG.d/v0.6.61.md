# v0.6.61

Production hardening: Logger persistence and timing integrity.

- Keep a Logger record charged to the bounded buffer until its filesystem append succeeds; explicitly account write-failed records.
- Count a successfully persisted record as written before retention/post-write callbacks run, so callback failures cannot reclassify durable data as unwritten.
- Timestamp Logger records at the producer/acquisition boundary and derive Measurement CSV local/elapsed timestamps from capture time rather than writer queue time.
- Frame Mixed CSV records with `RECORD_BEGIN` / `RECORD_END` so a crash cannot make an incomplete logical record appear complete.
- Replace per-record CSV fsync with configurable flush/fsync cadence while preserving final close durability.
- Mark segments failed rather than completed when append/close is tainted, and avoid rescanning every historical output path on each append.

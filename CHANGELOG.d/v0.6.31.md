# v0.6.31

### Added

- Implemented Automation backlog item **A10 Automation Profiles**.
- Added schema-versioned, validated JSON profile persistence with atomic writes.
- Profiles capture Automation mode/settings, measurement-slot selection, run limits, retention policy, File destination and naming settings.
- Loading a profile is permitted only while idle and never starts Automation automatically.
- Destructive retention authorization is deliberately cleared after profile load and requires a fresh retention preview.
- Transient runtime state/counters/timestamps are rejected from profile documents.
- Added profile round-trip, schema, transient-state and GUI driver-boundary tests.

### Version

- Package version bumped to `0.6.31`.

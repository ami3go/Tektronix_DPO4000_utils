# v0.7.0

- Made one serialized worker-owned DPO4054/VISA session the launched GUI default.
- Replaced nested Qt event-loop waits with asynchronous scope-action completions.
- Added cooperative cancellation, transport invalidation/reconnect and safe asynchronous window shutdown.
- Kept Core → REF → BUS refresh on one coherent connection while preserving staged failure isolation.
- Moved runtime VISA timeout/termination updates behind the public driver `configure_session()` API.
- Migrated production Automation A1..A7 and Logger capture state machines to callback-safe completion semantics; fixed A11 recovery to retry asynchronously.
- Preserved `BusDecodedEvent` positional compatibility and added an explicit decoded-BUS qualification capability contract without inventing undocumented SCPI.
- Added release dependency constraints and build-environment provenance artifacts.
- Added self-hosted 24/72-hour hardware soak tooling and workflow; a physical soak PASS still requires an actual DPO4054 bench run.
- Removed the temporary Ruff F401 debt baseline; only the intentional legacy wildcard re-export exemption remains.
- Added CI guards against nested `QEventLoop` regressions and synchronous `_run_action()` result consumption in the launched Automation/Logger path.

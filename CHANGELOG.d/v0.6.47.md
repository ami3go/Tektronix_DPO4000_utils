# v0.6.47

### Added

- Implemented Logger backlog item **L9 Retention**.
- Logger reuses the hardened ownership-index retention engine under the Logger output root instead of adding a second deletion implementation.
- Only closed segment groups are registered; the active segment is never eligible for deletion.
- Added retention by segment count, total Logger storage, age, and minimum-free-space guard.
- Path traversal, symlink substitution, root escape, and retention-index self-deletion remain fail-closed.
- Added live deleted-segment, reclaimed-space, and free-disk telemetry.

### Version

- Package version bumped to `0.6.47`.

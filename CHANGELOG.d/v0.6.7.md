# v0.6.7 - 2026-08-31

## Fixed

- CSV export now reads the oscilloscope's actual configured record length and explicitly requests that many waveform points, preventing a stale 10k `DATA:STOP` transfer window from truncating 100k, 1M, or 10M acquisitions.
- The high-level `save_all_channels_to_single_csv()` driver API now accepts explicit waveform-transfer options such as `point_count`.
- Added public `restore_default_setup()` support using `RECALL:SETUP FACTORY`, matching the DPO4000 front-panel default-setup action.

## Changed

- Renamed `Pick folder` to `Folder` and added `Open` to launch the configured destination directory in the platform file manager.
- Moved scope setup JSON naming/actions into a separate `Scope settings` card on the File page; the card participates in the existing collapsible-card behavior.
- Renamed Scope settings actions to `Save`, `Restore`, and `Default`.
- Successful CSV/settings save and restore operations no longer show informational popups; the resulting filename/status is written to Last operation and the bottom status bar.
- Shortened Acquisition setup buttons to `Read` and `Apply`.
- Shortened Channel labels buttons to `Read` and `Apply`.
- Shortened Display buttons to `Read`, `Apply`, and `Clear`.
- Package version bumped to `0.6.7`.

## Tests

- Added regression coverage for explicit 100k-point CSV transfer options and factory-default setup command handling.
- Added final-window metadata/runtime coverage for File/Scope settings layout, folder actions, concise button labels, non-modal file success feedback, and the updated GUI entrypoint chain.

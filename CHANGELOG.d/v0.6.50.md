# v0.6.50

### Added

- Implemented Logger backlog item **L11 Bounded Buffering**.
- Scope capture and disk persistence are now decoupled by a hard-bounded FIFO with independent record-count and estimated-memory limits.
- A dedicated writer thread exclusively owns CSV/DPO4LOG append, rotation, retention, and output close operations.
- Backpressure skips new scheduled captures when the queue is full instead of building an unbounded backlog.
- Post-capture queue rejection is counted explicitly as a dropped record and can stop the run after a configurable consecutive-overflow threshold.
- Pause continues draining the writer queue; Stop prevents new captures and drains queued records before final close.
- Added live queue depth, queued memory, peak depth, dropped records, write latency, and writer-error telemetry.

### Version

- Package version bumped to `0.6.50`.

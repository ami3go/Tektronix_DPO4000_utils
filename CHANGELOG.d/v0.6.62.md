# v0.6.62

Production hardening: streaming DPO4LOG tooling.

- Make `scan_dpo4log()` bounded-memory by default and require explicit `load_records=True` for whole-file materialization.
- Add `iter_dpo4log_records()` for one-record-at-a-time conversion and processing.
- Add frame/header safety limits, clean-END detection and truncated/corrupt status.
- Preserve `captured_monotonic` in binary records.
- Add the `dpo4000-log inspect` and `dpo4000-log convert --csv` command-line entry point.
- Add regression coverage for bounded scans, recovery and streaming conversion.

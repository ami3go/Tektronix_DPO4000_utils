# v0.6.51

### Fixed

- Reviewed and hardened Logger **L11 Bounded Buffering**.
- Writer initialization timeout now revokes future queue acceptance before returning control to the GUI.
- A timed-out startup keeps the still-owned writer thread visible to the GUI until it actually exits, preventing a second Logger run from opening overlapping output writers.
- Writer failures are counted exactly once even when the operator subsequently presses Stop.
- Failure-state shutdown continues to let the writer thread exclusively own output close/finalization.

### Version

- Package version bumped to `0.6.51`.

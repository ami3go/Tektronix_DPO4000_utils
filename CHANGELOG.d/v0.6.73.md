# v0.6.73

## Added

- Added opt-in pytest hardware-in-the-loop coverage for the final Automation and Logger GUI tabs.
- Added a PROBE COMP topology that uses the oscilloscope calibration output on CH1 to qualify fresh-trigger Automation, all Automation modes, Logger waveform/MATH/measurement/mixed paths, CSV/DPO4LOG output, pause/resume, rotation, retention, buffering, health telemetry and final reports.
- Added PicoScope 2206B AWG HIL using PicoSDK `ps2000aSetSigGenBuiltIn` to generate sine, square and triangle qualification signals and drive Conditional Automation plus Mixed Logger capture.
- Added dynamic Automation/Logger option-widget traversal so every value-bearing GUI option is exercised and profile round-tripped.
- Added a dedicated self-hosted `Automation and Logger GUI HIL` GitHub Actions workflow and bench setup documentation.
- Added the `hil` optional dependency group with PySide6, pytest and PicoSDK Python wrappers.

## Safety

- GUI HIL is gated by `DPO4000_GUI_HIL=1` and `DPO4000_ENABLE_WRITE_TESTS=1`.
- PROBE COMP and Pico AWG tests use only analog stimulus. BUS Logger is covered through its hardware-capability gate; transaction-level decoded BUS HIL remains reserved for a dedicated serial-bus stimulus fixture.

# v0.6.57

### Added

- Implemented Logger backlog item **L14 Run Report**.
- Added crash-tolerant Logger reports with sparse durable JSONL/CSV lifecycle events, atomic periodic checkpoint JSON, and atomic final summary JSON.
- Final reports include profile/config snapshot, package version, scope resource/IDN, UTC/local start/end timestamps, elapsed time, output segments, selected sources, produced/written/skipped/dropped/error counts, waveform/MEAS/BUS totals, byte/throughput metrics, queue peaks, reconnect/retry statistics, retention deletions and termination reason.
- Added record reconciliation showing captured records versus written + dropped + queued records and writer terminal state.
- Report finalization waits for the dedicated writer thread to close/register the final segment before writing the final summary.
- Added Open report / Open report folder controls in Logger runtime health.
- Logger retention now exposes the closed segment groups registered during a run so reports can preserve the complete output manifest even after retention deletes old segments.

### Version

- Package version bumped to `0.6.57`.

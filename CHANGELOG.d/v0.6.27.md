# v0.6.27

### Added

- Implemented Automation backlog item **A8 Run Duration/Count Limits**.
- Added optional maximum successful-event count and maximum elapsed wall-clock duration; the first reached boundary stops the run.
- Added a framework-neutral `RunLimitTracker` with remaining-count/time and explicit stop-reason reporting.
- Applied limit checks to periodic/conditional/logging ticks, trigger cycles, Image+CSV trigger cycles, Burst scheduling, and a duration watchdog.
- Added remaining-event/time and stop-reason fields to the Run Limits card.
- Run-limit controls are locked while automation is active; Run once remains independent of recurring run limits.
- Added validation, boundary, and GUI driver-boundary tests.

### Version

- Package version bumped to `0.6.27`.

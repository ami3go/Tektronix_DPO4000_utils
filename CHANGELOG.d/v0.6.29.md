# v0.6.29

### Added

- Implemented Automation backlog item **A9 File Retention** with persistent ownership indexing.
- Added event-level retention by last N events, maximum automation storage, maximum age, and minimum free disk space.
- Added dry-run preview gating: automatic deletion cannot be enabled until the current policy has been previewed.
- Added fail-closed root containment, malformed-index rejection, symlink rejection, atomic index writes, and revalidation immediately before deletion.
- Retention deletes only completed artifacts registered by Automation; unregistered files are never eligible.
- Image + CSV artifacts remain one retention event, while active append-only Measurement Logger files are deferred until the run stops.
- Output-root changes during an active run cause a safety stop rather than widening retention scope.
- Added per-deletion/reclaimed-byte logging and minimum-free-space safety stop behavior.

### Version

- Package version bumped to `0.6.29`.

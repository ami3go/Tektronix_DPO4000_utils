# v0.6.44

### Added

- Implemented Logger backlog item **L7 Mixed/synchronized record**.
- Mixed mode can combine CH1..CH4, MATH, MEAS1..MEAS8 and qualified BUS events under one acquisition ID.
- Each mixed record arms Single, waits for acquisition completion, then reads requested scope-side data before the next record can arm.
- Non-transport component failures are preserved as explicit partial-record metadata; transport failures abort the record.
- Stop can cancel the active Single wait.
- Added tagged-row mixed CSV output; DPO4LOG already stores the same grouped record natively.

### Version

- Package version bumped to `0.6.44`.

# v0.6.21

### Fixed after A5 review

- Measurement-slot checkboxes are now locked while any scope operation is in flight, including Measurement Logger Run once, so the visible selection cannot drift from the immutable slot snapshot being recorded.
- Existing non-empty measurement CSV files now have their header validated before every append; a mismatched schema stops the run instead of silently corrupting fixed-column data.
- Boolean slot values are rejected explicitly instead of being accepted as MEAS1/MEAS0-style integer aliases.
- Added regression coverage for header mismatch protection and in-flight UI locking.

### Version

- Package version bumped to `0.6.21`.

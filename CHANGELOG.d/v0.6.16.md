# v0.6.16

### Added

- Implemented Automation backlog item **A3 Image + CSV on Trigger**.
- Added a third Automation mode that arms one Single acquisition, waits for completion, then saves a PNG image and full enabled-channel CSV before any re-arm occurs.
- Added framework-neutral `acquire_trigger_bundle(...)` orchestration so the same-acquisition call order is unit-testable without Qt.
- PNG and CSV use one shared event sequence and timestamp source while still honoring the existing File-page naming settings and collision-safe output policy.
- Added Current Run visibility for the latest CSV artifact and mode-aware action presentation.
- Added tests proving PNG is saved before full-record CSV, cancellation writes no artifacts, CSV failures do not arm another acquisition, and the GUI remains behind the public driver boundary.

### Safety / semantics

- A3 does not re-arm until both requested artifacts have been handled successfully.
- A partial artifact left by a disk/transfer failure is preserved and reported instead of being silently deleted.
- No raw SCPI/PyVISA implementation was added to the A3 GUI layer.

### Version

- Package version bumped to `0.6.16`.

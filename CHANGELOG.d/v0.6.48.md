# v0.6.48

### Added

- Implemented Logger backlog item **L10 Automatic Reconnect**.
- Logger now reuses the existing serialized A11 action-attempt/session recovery path; no second VISA/SCPI connection path is introduced.
- Added Logger-specific retry count, linear backoff, and consecutive-failure stop threshold controls.
- Replay-safe Logger capture operations can reconnect and retry after classified transport failures.
- Exhausted transport retries can skip a record and continue until the configured consecutive-failure threshold is reached.
- Non-transport acquisition/output failures still fail immediately.
- Unified Logger capture handling now prevents all modes from appending a stale worker completion after Stop closes the output session.

### Version

- Package version bumped to `0.6.48`.

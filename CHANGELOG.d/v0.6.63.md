# v0.6.63

Production hardening: retention ownership and transactional deletion.

- Namespace retention ownership so Automation and Logger policies cannot select each other's artifacts when sharing an output root.
- Preserve backward compatibility by treating legacy index entries without an owner as Automation-owned.
- Stage all deletion candidates with atomic renames before committing the updated ownership index.
- Roll staged files back if any pre-commit filesystem/index operation fails.
- Fsync the retention index parent directory after atomic replacement on platforms that support it.
- Add regression coverage for cross-owner isolation and rollback on partial staging failure.

# v0.6.52

### Added

- Implemented Logger backlog item **L12 Logger Profiles**.
- Added schema-versioned JSON profiles for mode, CH/MATH/MEAS/BUS source selection, interval, output format/root, Keep session, rotation, retention, reconnect, and bounded-buffer policies.
- Added Logger profile New / Save / Save As / Import / Export controls.
- Profile load performs complete schema and UI-compatibility preflight before the first widget mutation and never starts Logger automatically.
- Unknown top-level or nested profile fields, non-finite values, unsupported transfer settings, and values that cannot be represented exactly by the current UI are rejected instead of silently ignored or rounded.
- Profile files never contain runtime counters, queue contents, writer state, timestamps, or running/paused state.
- Strengthened `LoggerConfig` validation so waveform encoding and sample width fail before hardware capture.

### Version

- Package version bumped to `0.6.52`.

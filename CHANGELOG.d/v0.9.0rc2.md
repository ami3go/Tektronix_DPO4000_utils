# v0.9.0rc2 — four-channel Live View candidate

- Replace the narrow single-channel Measurement-card prototype with a dedicated
  top-level Live workspace and large central CH1–CH4 canvas.
- Publish sequential channel transfers only as complete alignment-validated groups,
  with explicit per-channel timing, skew, group-rate and transport metrics.
- Retain Preview state, bounded latest-group scheduling, the serialized scope lease,
  and backwards-compatible single-channel engine calls.
- Add production-window, four-channel domain/heartbeat, packaging-contract, and
  opt-in USB/TCPIP DPO4054 HIL coverage.
- Live View reads each channel at the scope's own record length (no transfer-size
  selector), refuses a record above 1M samples before `CURVE?`, and fails fast with
  a clear message when a selected channel is not displayed.
- Speed up live streaming: one `WFMOUTPRE?` query replaces nine per-field queries,
  and Live View reuses the preamble (`PreambleCache`) while a cheap fingerprint of
  the horizontal and per-channel settings is unchanged (refreshed at least every
  5 s), decoding the sample block from raw bytes. On the DPO4054, one four-channel
  100k-point group dropped from about 800 ms to about 500 ms over USB and from
  about 970 ms to about 720 ms over VXI-11. The public read API still re-reads the
  preamble every time.
- Add per-channel info cards and an auto/fixed vertical grid to the Live View.

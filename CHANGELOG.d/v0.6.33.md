# v0.6.33

### Added

- Implemented Automation backlog item **A11 Automatic Reconnect**.
- Added bounded transport retry policy (default 2 retries, 1 s base delay, stop after 5 consecutive exhausted failures).
- Refactored the existing worker/session path to expose one reusable action-attempt gateway; no second VISA/SCPI path is introduced.
- Retained sessions are invalidated on transport failure and recreated through the existing persistent-session worker.
- Retry reconnects verify scope identity before replaying the automation action.
- Only explicitly replay-safe Automation operations are retried; evidence bundles and other ambiguous partial side effects fail closed instead of being blindly replayed.
- Added retry/reconnect/transport-failure telemetry and profile persistence for recovery settings.

### Version

- Package version bumped to `0.6.33`.

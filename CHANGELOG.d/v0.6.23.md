# v0.6.23

### Fixed after A6 review

- Stopped conditional runs now ignore stale worker completions before those completions can update condition state or restart stop handling.
- Normal condition misses now clear a previous transient invalid-read message from controller state instead of leaving stale error text behind.
- Structured Image + CSV failures now include any successfully written partial artifact paths in the error text so evidence is not silently lost.
- Added review-layer and controller regression coverage for stale-generation and skipped-event behavior.

### Version

- Package version bumped to `0.6.23`.

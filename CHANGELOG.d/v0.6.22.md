# v0.6.22

### Added

- Implemented Automation backlog item **A6 Conditional Capture**.
- Added MEAS1..MEAS8 condition selection with `>`, `>=`, `<`, `<=`, inside range, outside range, and absolute-delta operators.
- Added configurable consecutive-match debounce and enforced cooldown before another conditional capture may fire.
- Added Image, CSV, and Image + CSV conditional artifact actions using public driver APIs only.
- Added invalid/sentinel measurement handling that resets debounce and never counts an invalid read as a condition match.
- Added paired collision-safe naming for conditional Image + CSV artifacts and structured partial-artifact failure reporting.
- Added a framework-neutral conditional evaluator/poll helper plus regression tests.
- Added `finish_skipped()` to the existing Automation controller so condition polls that do not capture do not inflate success counters.

### Version

- Package version bumped to `0.6.22`.

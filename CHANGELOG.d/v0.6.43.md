# v0.6.43

### Added

- Implemented Logger backlog item **L6 BUS decoder logger** pipeline and UI.
- Added normalized BUS event CSV and DPO4LOG serialization for BUS1..BUS4.
- Added a public structured `BusDecodedEvent` contract and explicit driver capability methods.
- The stock DPO4000 driver deliberately reports decoded-event extraction as unavailable until the exact programmer-manual command and hardware response are qualified; Logger blocks BUS start instead of guessing an undocumented command.

### Version

- Package version bumped to `0.6.43`.

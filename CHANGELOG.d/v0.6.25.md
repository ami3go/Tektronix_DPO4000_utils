# v0.6.25

### Added

- Implemented Automation backlog item **A7 Burst Capture**.
- Added finite successful-event count and configurable delay between completed events.
- Added Image, CSV, and Image + CSV burst artifacts using the shared public-driver artifact helper.
- Added optional Single-acquisition sequencing that waits for acquisition completion before saving artifacts.
- Added cancellation while waiting for Single; active artifact writes are allowed to complete safely.
- Reused the existing Automation controller/timer with no separate GUI loop or overlapping scope operations.
- Added exact-count, cancellation, transport, ordering, and driver-boundary regression coverage.

### Version

- Package version bumped to `0.6.25`.

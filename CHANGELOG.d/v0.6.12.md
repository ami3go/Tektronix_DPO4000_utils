# v0.6.12

### Added

- Implemented Automation backlog item **A1 Periodic Image**.
- Added a top-level Automation page after Acquisition with the canonical Status & Control, Automation Mode, Actions, Run Limits, Output & Retention, Reliability, and Current Run cards.
- Added periodic PNG capture with configurable seconds/minutes/hours interval, Run once, Start, Pause/Resume, and Stop controls.
- Periodic scope work is routed through the existing serialized `_run_action` path and public `save_image_path()` driver API; Automation code contains no raw SCPI/PyVISA operations.
- Added strict no-overlap/no-backlog behavior: timer ticks arriving during an active capture are counted as skipped rather than queued.
- Automation PNG paths reuse File-page folder/prefix/base/timestamp settings, append a four-digit event sequence, and allocate a collision-safe suffix instead of silently overwriting files.
- Added a Qt-independent periodic-image controller with stale-completion protection and unit tests.
- Updated launched GUI navigation to include Automation and Ctrl+1..9 page shortcuts.

### Version

- Package version bumped to `0.6.12`.

# v0.6.58

### Fixed

- Reviewed and hardened Logger L14 report durability.
- JSONL is now the authoritative sparse event stream: once a JSONL event is fsynced it is counted even if the secondary CSV event write fails.
- Runtime report-event failures now stop Logger fail-closed instead of silently disabling later checkpoints.
- A failed RUN_END event write can no longer prevent the authoritative final JSON summary from being written.
- Checkpoint documents now use explicit `status: checkpoint` semantics rather than presenting failure/stop checkpoints as running.
- Added regression coverage for JSONL/CSV partial-write behavior and final-summary independence.

### Version

- Package version bumped to `0.6.58`.

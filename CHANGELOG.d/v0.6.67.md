# v0.6.67 — Permanent Qt GUI driver-boundary guard

- Replaced the four-file legacy GUI boundary check with an AST-based regression test that automatically scans every current and future `dpo4000_utils/gui_qt` Python module.
- The guard rejects raw PyVISA imports, direct low-level query/write/read transport methods, access to raw scope/resource/instrument handles, and reintroduction of the historical GUI-owned SCPI query maps.
- This makes the GUI-as-wrapper architecture an enforced CI contract rather than a convention tied to a fixed list of GUI files.

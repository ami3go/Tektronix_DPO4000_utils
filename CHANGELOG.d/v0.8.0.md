# v0.8.0 — Qt composition architecture

- Launch DPO4000 Desk from a shallow `QMainWindow` composition shell rather than the historical multi-window inheritance chain.
- Add explicit controllers for scope dispatch, lazy page construction/navigation, preferences, logging, output paths, frameless window chrome, and lifecycle/shutdown.
- Expose named page controllers for Connection, Channels, Measurement, Trigger, Acquisition, File, Display, and Log.
- Isolate the mature v0.7 feature implementation behind one compatibility adapter; legacy `*_window.py` classes are no longer production launch ancestors.
- Route all mature feature-surface scope actions through the composed scope controller while preserving the v0.7 persistent asynchronous worker/session contract.
- Rewire titlebar minimize/maximize/close and drag behavior to the composed top-level window.
- Add architecture regression tests that enforce a shallow production MRO, a single approved legacy adapter, explicit controller dependencies, and no raw VISA/SCPI ownership in the composition layer.
- Preserve all existing Automation A1..A12, Logger, BUS, preview, acquisition, measurement, settings, and persistent-session behavior behind the compatibility surface.

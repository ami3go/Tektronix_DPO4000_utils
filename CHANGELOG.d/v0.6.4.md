# v0.6.4 - 2026-08-31

## Fixed

- Canonicalized Tektronix abbreviated acquisition-mode query responses before they reach the public API or GUI; `HIR` now displays and round-trips as `HIRES`.
- Changing only horizontal record length after reading a Hi Res acquisition setup no longer re-submits the invalid application value `HIR` and therefore no longer fails the acquisition update path.
- Automatic post-connection snapshots and explicit acquisition readback now receive the same canonical acquisition-mode labels from the driver.

## Changed

- `HIRES` is the single application/API label for Hi Res acquisition mode. `HIR` remains unsupported as user/API command input; it is decoded only when received as a minimum-form Tektronix SCPI response.
- Package version bumped to `0.6.4`.

## Tests

- Added regression coverage for `HIR` readback canonicalization, strict rejection of `HIR` command input, all minimum-form acquisition readbacks, and the record-length-only update scenario.

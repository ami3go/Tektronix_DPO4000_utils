# v0.6.30

### Fixed after A9 review

- Automatic-deletion authorization is now bound to the exact resolved output root that was previewed.
- Changing the File destination after a preview invalidates deletion authorization and requires a fresh preview before Start/Run once.
- When automatic deletion is enabled, retention is evaluated once at run start so previously tracked files can be cleaned before the first new capture.

### Version

- Package version bumped to `0.6.30`.

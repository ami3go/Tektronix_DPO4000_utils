# v0.6.5 - 2026-08-31

## Changed

- Renamed the quick `Capture` action to `Preview` and the quick `PNG` action to `Image`.
- `Preview` now captures the current oscilloscope screen entirely in memory and updates the GUI without creating or overwriting a user PNG file.
- `Image` continues to save a persistent PNG using the configured output folder, prefix/base name, and timestamp settings, and also refreshes the preview.
- `Copy` now copies the full-resolution in-memory preview, so it works after `Preview` even when no image file exists on disk.
- Package version bumped to `0.6.5`.

## Tests

- Added source-level regression coverage proving `Preview` uses `read_screen_png()` without file-path/save calls and `Image` uses the persistent `save_image_path()` path.
- Updated the final PySide6 entrypoint boundary checks for the new Preview/Image action layer.

# v0.6.17

### Fixed after A3 review

- PNG and CSV collision handling now advances both artifact names with one shared suffix, preserving obvious evidence-pair identity when either requested file already exists.
- Non-transport image/CSV serialization or filesystem failures are returned as structured partial A3 results instead of being routed through the generic transport-failure path.
- Transport failures still propagate normally so retained VISA sessions can be invalidated and recovered by the existing connection policy.
- Partial A3 results retain any successfully created artifact and report it explicitly; the next Single acquisition is not armed after a partial failure.
- Added regression coverage for shared collision suffixes and structured disk-write failures.

### Version

- Package version bumped to `0.6.17`.

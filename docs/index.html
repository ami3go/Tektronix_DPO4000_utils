Tektronix DPO4000 / DPO4054

Python driver and modern bench GUI for DPO4000 oscilloscopes.

Use USB/VISA or Ethernet, capture scope screenshots, export waveform CSV files, manage displayed measurements, control trigger/acquisition settings, and package the GUI as Windows/Linux executables.

View on GitHub Releases Build guide

PySide6 bench GUI

Compact frameless titlebar with Connection, Channels, Measurement, Trigger, Acquisition, File, Display, and Log pages.

Shared driver API

Scriptable DPO4054/DPO4000 control for labels, screenshots, waveform CSV export, measurements, setup save/restore, trigger, and acquisition.

Executable builds

PyInstaller helper scripts and GitHub Actions workflow produce Windows and Linux GUI artifacts without requiring hardware during packaging.

Quick start

python -m pip install -e .[pyside6]
dpo4000-gui-qt

For real instrument communication, install a VISA runtime/backend such as NI-VISA, TekVISA, Keysight VISA, or a compatible PyVISA backend.

Core features

  • USB/VISA and Ethernet VISA resource support.
  • PNG scope hardcopy capture with preview and clipboard copy.
  • Enabled-channel waveform export to CSV.
  • Measurement slot management for MEAS1..MEAS8.
  • Trigger level, edge trigger, and acquisition controls.
  • Dedicated File and Display pages for output and front-panel display settings.

Hardware access requires a connected Tektronix DPO4000-family oscilloscope and a working VISA backend.

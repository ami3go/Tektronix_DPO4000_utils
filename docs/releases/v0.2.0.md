# dpo4000-utils v0.2.0 / DPO4000 Desk

This release promotes the new **DPO4000 Desk** oscilloscope desktop application layout and packaging flow while keeping `dpo4000-utils` as the Python library/package name.

## Highlights

- Modern compact DPO4000 Desk GUI with page buttons in a custom titlebar.
- Primary desktop command: `dpo4000-desk`.
- Draggable titlebar tabs for moving the frameless window.
- Dedicated **File** and **Display** pages.
- Display controls for backlight/contrast, waveform intensity, graticule intensity, persistence, and scope screen text.
- Existing `MEAS1..MEAS8` measurement management:
  - read configured slots
  - load a slot into the editor
  - apply edits to a selected slot
  - read selected value
  - delete/disable selected measurement
- Cleaner preview area without the obsolete `Screen preview` title band.
- Larger measurement-manager buttons.
- Windows/Linux PyInstaller build scripts and release workflow support.
- Linux release packaging for `.deb`, AppImage, and Flatpak bundle artifacts.

## Recommended downloads

- Windows: `DPO4000Desk-windows.exe`
- Debian/Ubuntu Linux: `dpo4000-desk_0.2.0_amd64.deb`
- Other Linux desktops: `DPO4000Desk-x86_64.AppImage`
- Flatpak users: `DPO4000Desk.flatpak`
- Raw Linux binary: `DPO4000Desk-linux`

## Runtime requirements

The packaged app includes the Python GUI dependencies, but real instrument access still requires a VISA runtime/backend on the target PC, for example NI-VISA, TekVISA, Keysight VISA, or another PyVISA-compatible backend.

## Hardware note

This release should be manually checked with a real DPO4000/DPO4054 scope before production bench use. CI/build checks do not verify physical SCPI behavior.

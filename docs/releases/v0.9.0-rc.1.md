# DPO4000 Utils v0.9.0-rc.1

This release candidate contains the complete v0.9 automation, evidence, trend, scientific
export, and headless execution feature set. It is published for final DPO4054 qualification
and must not be treated as the stable v0.9.0 release until the retained hardware evidence
listed below has passed review.

## Highlights

- Advanced A-trigger and Sequence/B-trigger configuration, holdoff, capability probing,
  and asynchronous Desk integration.
- Validated JSON test recipes with pause/resume/cancel, bounded retries, timing capture,
  and serialized public-driver execution.
- Deterministic pass/fail rules and atomic evidence bundles for automated test workflows.
- Bounded measurement trends with decimation and GUI backpressure protection.
- Lossless NumPy NPZ and portable DPOZ waveform archives with safe import validation.
- `dpo4000-job` for headless recipe execution, atomic reports, and automation-friendly exit
  semantics.
- Reviewed R0 functional/timing regression tooling with USB/TCPIP-specific performance
  baselines.

## Candidate qualification

- Hosted Python 3.10–3.13, Ruff, PySide6, and CodeQL gates must pass.
- Windows ZIP, Linux binary, AppImage, Debian, Flatpak, SBOM, checksums, and provenance
  gates must pass for this exact candidate commit.
- DPO4054 API/HIL and separate USB/TCPIP performance comparisons must pass.
- The required 24-hour DPO4054 soak must pass and its retained report must be reviewed.

See `docs/releases/v0.9.0.md` for the complete stable-release notes draft.

# DPO4000 Utils v0.9.0

**Draft stable-release notes (2026-10-24):** 0.9.0 is not yet a hardware-qualified stable release. The software described here is delivered in the 0.9.0rc1 candidate; required live DPO4054 hardware evidence remains pending. The A22 stream, A25 hardening and P0 release-guard draft pull requests are not included in that candidate.

v0.9.0 expands DPO4000 Desk from interactive instrument control into a complete,
reproducible test-automation workflow while keeping all instrument I/O behind the public
driver and serialized worker boundary established in v0.7/v0.8.

## Advanced trigger control (A14)

- Configure pulse-width, runt, timeout, logic, setup/hold, video, and Sequence/B-trigger
  families through validated public APIs and the composed Trigger page.
- Read and write trigger holdoff with exact command-contract coverage.
- Probe option-dependent trigger capabilities with bounded timeouts and transport-aware
  failure handling.

## Test recipes and pass/fail rules (A15/A16)

- Define versioned JSON recipes containing validated public-driver calls and deterministic
  delays.
- Pause, resume, cancel, and retry recipes without taking over the VISA/session lifecycle.
- Evaluate numeric, range, delta, AND, OR, and NOT rules against completed recipe results.
- Present `PASS`, `FAIL`, and `INVALID` outcomes in DPO4000 Desk without additional scope
  traffic.

## Evidence and trends (A18/A20)

- Create atomic evidence bundles with manifests, hashes, reports, and captured artifacts.
- Reject unsafe or corrupted archives during verification.
- Display bounded measurement histories with decimation and explicit queue/backpressure
  behavior suitable for long-running sessions.

## Scientific export (A21)

- Export acquired `WaveformData` to lossless NumPy NPZ or portable DPOZ archives.
- Round-trip exact raw samples and waveform preambles.
- Validate archive paths, sizes, checksums, and structure before import.
- Use the composed File page for full, 1k, 10k, 100k, and 1M-point scientific captures.

## Headless automation (A25)

- Run recipes without the desktop GUI through `dpo4000-job`.
- Produce deterministic, atomically replaced JSON reports and automation-friendly exit
  codes.
- Preserve the same validation, rule, evidence, and public-driver boundaries as Desk.

## Regression and release engineering

- Add the reviewed R0 functional and timing framework, including normalized snapshots,
  malformed-input/zero-I/O matrices, fake transport latency and fault tests, deterministic
  scheduling tests, logger backpressure, and GUI heartbeat responsiveness.
- Add batch orchestration and tools to capture and compare separate USB and TCPIP DPO4054
  performance baselines using relative and absolute p95 gates. Final physical baseline
  measurements and reviewer acceptance are release gates, **not completed deliverables**.
- Build and smoke-test Windows ZIP, Linux binary, AppImage, Debian, and Flatpak artifacts
  from pinned dependencies.
- Retain resolved Python environments, SHA-256 manifests, SPDX SBOMs, and provenance
  attestations with release artifacts.

## Compatibility

- Python 3.10–3.13 remains supported.
- Existing public driver, Automation A1–A12, Logger, BUS/REF, waveform, settings, and Desk
  workflows remain supported.
- New recipe files, rule sets, evidence bundles, and scientific archives are versioned and
  validated before execution or import.

## Stable publication gate

Stable publication is permitted only after all of the following evidence from the final
candidate tree is retained and reviewed:

- hosted test, GUI, lint, CodeQL, package, checksum, SBOM, and provenance jobs;
- full DPO4054 public-API/HIL qualification;
- separate USB and TCPIP timing-baseline comparisons;
- a successful 24-hour DPO4054 soak with no disallowed failure, resource-growth, or timing
  regression.

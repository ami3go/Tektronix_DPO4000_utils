# dpo4000-utils v0.4.0

v0.4.0 makes DPO4000 Desk the project's single supported desktop frontend.

## Highlights

- PySide6-only desktop application.
- Removed the former Tk frontend and `dpo4000-gui` command.
- Removed archived Tk GUI snapshots and Tk-specific tests.
- Preserved the reusable `dpo4000_utils` driver/API.
- Preserved the API-only GUI-to-driver boundary introduced in v0.3.0.
- Added CI coverage that installs PySide6 and runs the full suite with `QT_QPA_PLATFORM=offscreen`.

Install the desktop application dependencies with:

```bash
python -m pip install -e .[pyside6]
dpo4000-desk
```

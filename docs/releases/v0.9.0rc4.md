# DPO4000 Desk v0.9.0rc4 (release candidate)

**This is a release candidate, not the hardware-qualified stable release.** It
supersedes `v0.9.0rc3`.

## What changed since rc3

- New offline USB/Ethernet transport-switch soak runner
  (`scripts/run_transport_switch_soak.py`): one exclusive VISA session alternates
  between USB and Ethernet, both resources are verified to be the same instrument,
  and a cycle-level journal is fsynced for unattended runs.
- The DPO4054's `TRIGGER:STATE?` abbreviation `REA` is now reported as `READY`.

## Qualification status (honest summary)

- Bench evidence on a DPO4054: a 24 h USB/Ethernet handoff soak passed (8640 samples,
  0 failures, 47/47 handoffs, 0 missed deadlines; RSS 49.8 to 62.6 MiB). Report
  retained in `qualification_reports/soak/transport-switch-24h-20261030-194938/`.
  It is scope-only, not exact-head and not independently reviewed.
- **Not yet done:** the formal P0-G3 24 h read-only soak (the 27 Oct attempt was
  interrupted), USB matrix, 1M-point runs, disconnect and clean-close tests,
  packaged-build screenshots, and independent review.
